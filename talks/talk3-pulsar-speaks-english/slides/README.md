# Slides: When Your Pulsar Function Speaks English: Inline LLM Inference for Real-Time Stream Enrichment

- `When-Your-Pulsar-Function-Speaks-English.html`: standalone copy. Opens offline in any browser, and keeps animations, audio and video. Use arrow keys to navigate.
- `source/`: the editable project, exported from Claude Design. Open `source/Talk 3 Pulsar Speaks English.dc.html` through a local web server, e.g. `cd source && python3 -m http.server`, then visit http://localhost:8000. Re-import this folder into Claude to keep editing.
  - `_ds/` holds the Datadog presentation design system tokens and the DRUIDS fonts.
  - `assets/` holds the backgrounds, logos, chart, audio clips and demo video the deck uses.
  - `DatadogDeck.dc.html` is the design system's sample deck, not part of the talk.
- PDF: open the standalone HTML and print to PDF (one page per slide).
