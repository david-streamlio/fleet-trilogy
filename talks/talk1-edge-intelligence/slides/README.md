# Talk 1 slides: Squeezing Intelligence into the Dumb Pipe

- `Talk1-Edge-Intelligence.pptx`: conference deck, with editable text and shapes and speaker notes. Animations and interactive toggles are flattened.
- `Talk1-Edge-Intelligence.html`: standalone copy. Opens offline in any browser, and keeps animations and interactions. Use arrow keys to navigate.
- `source/`: the editable project. Open `source/Talk 1 Edge Intelligence.dc.html` through a local web server, e.g. `cd source && python3 -m http.server`, then visit http://localhost:8000. Re-import this folder into Claude to keep editing.
  - `.image-slots.state.json` stores the images dropped into the image slots. Keep it with the deck.
  - `_ds/` holds the DRUIDS tokens, fonts and bundle.
  - The `*.md` files are the slide plan, the Talk 2 handoff and the open TODOs.
- PDF: open the standalone HTML and print to PDF (one page per slide).
