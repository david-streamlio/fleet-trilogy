# Deck rules (Talk 2 Greenest Token)

Avoid "AI-generated slide" tells:
- Body text at least 36px; captions/labels at least 30px; footer 24px is the only exception. Titles 56px+.
- No more than ~40 visible words on a content slide. Detail, caveats and numbers that aren't the point go in speaker notes.
- No "card" pattern: bordered/gray box holding icon + bold title + paragraph. Use open layout on white: one big statement or number per idea.
- One idea per column; at most 2–3 columns.
- No crowded slides: one focal element (a code box, a diagram or one big number) plus at most one supporting element. If a slide has a label line, a box, stats and a callout, cut to the essentials and move the rest to speaker notes. Leave generous whitespace.
- Don't repeat a stat that already appeared on an earlier slide.
- Boxes only for real things (code, prompts, diagrams), not for wrapping prose.
- Keep the user's wording when shortening; move cut text to the slide's speaker notes rather than deleting it.
