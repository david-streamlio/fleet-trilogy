# Slides: The Greenest Token Is the One That Never Hits a GPU

- `The-Greenest-Token-Is-the-One-That-Never-Hits-a-GPU.html`: standalone copy. Opens offline in any browser, and keeps animations and interactions. Use arrow keys to navigate.
- `source/`: the editable project, exported from Claude Design. Open `source/Talk 2 Greenest Token.dc.html` through a local web server, e.g. `cd source && python3 -m http.server`, then visit http://localhost:8000. Re-import this folder into Claude to keep editing.
  - `_ds/` holds the DRUIDS tokens, fonts and bundle.
  - `assets/` holds the images and charts the deck uses; `uploads/` holds the original uploads.
  - `CLAUDE.md` holds the deck's style rules.
- `charts/`: the slide charts as SVG and PNG.
- PDF: open the standalone HTML and print to PDF (one page per slide).
